## 로컬 운용 방식

E 드라이브에서 기본 Dry Run collector:run으로 현재 상태를 확인한다. 승인된 Source·목적·약관·robots·호스트·local budget이 따로 충족된 경우에만 기존 collector:run의 apply를 사용할 수 있다. 실제 시작 여부는 개별 승인에 따른다. 체크포인트는 E의 로컬 staging D1에 남고 접근 간격, 호스트 gate, retry, cursor 및 owner를 이용해 다음 호출에서 재개한다. PC가 꺼진 동안에는 수집을 실행할 수 없고 스케줄러 서비스를 이번 작업에서 설치하지 않았다.

3시간 간격으로 하루 8번 실행하더라도 로컬 단일 CLI는 한 번에 한 작업을 진행한다. 문서 수집과 저장이 별개이고 요청 지연·사이트맵·승인·오류에 따라 회전 횟수가 줄어들 수 있다. 47현과 VTuber 공정성의 기존 계약을 보존한다. 단일 CLI의 기본 선택은 일반 지역 lane으로, 별도 VTuber 스케줄과 완주 지연은 통합 실증 전까지 보장하지 않는다. 현재 활성 정보원은 0개다.

로컬 D1은 Cloudflare D1 REST 자격 증명이나 원격 쓰기를 사용하지 않는다. 원격 데이터 전달이 필요해지면 승인된 staging 스키마와 좁은 인증·audience, 후보 본문 상한, 원본 provenance, idempotency/fingerprint, 출처 재확인과 원격 read/write 예산을 포함한 인수 경계를 별도로 승인·실증한다. 원격 D1 직접 SQL이나 저장소 동기화로 이 경계를 우회하지 않는다.

Workers Free 공식 한도는 CPU 10ms, 메모리 128MB, subrequest 50/호출, 동시 외부 연결 6, 요청 10만/일, Cron 5/계정이다. D1 Free는 50쿼리/호출, 일 읽기 500만·쓰기 10만, DB 500MB·계정 저장 5GB다. 로컬 DNS/TLS/해제 비용은 PC에서 들며 Cloudflare CPU·subrequest·D1 사용량과 따로 다룬다. 실제 새 경로의 Cloudflare CPU는 미측정이다.
